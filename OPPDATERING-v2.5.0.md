# Treningslogg v2.5.0 – Øvelsesbank

## Nytt
- Felles øvelsesbank for Håvard og Stine.
- Alle øvelser som finnes i programmene ved oppstart legges automatisk i banken.
- Alternative øvelser fra programmene legges også inn som egne bankøvelser.
- Nye øvelser kan opprettes og redigeres direkte i banken.
- En bankøvelse kan lagre standard sett, reps, tempo, pause, RIR/notat, alternativer og om den er en kroppsvektøvelse.
- I programeditoren kan øvelser legges til direkte fra banken.
- Nye øvelser som skrives inn manuelt i programeditoren blir automatisk lagt i banken når programmet lagres.
- Engangsøvelser under en pågående økt kan velges fra banken.
- Banken synkroniseres via samme Supabase-konto som programmer og historikk.

## Oppdatering
1. Eksporter full backup i dagens app.
2. Trykk «Synkroniser nå» og kontroller at synk fungerer.
3. Last opp alle filene i denne mappen til samme GitHub Pages-repo og erstatt eksisterende filer.
4. Ingen SQL-endring er nødvendig.
5. Åpne GitHub Pages-adressen i Safari. Hvis gammel versjon vises, åpne adressen med `?v=2.5.0` én gang.
6. Kontroller at Data-fanen viser Treningslogg v2.5.0.
7. Gå til Program → Øvelsesbank. Banken fylles automatisk fra eksisterende programmer.
8. Opprett gjerne én testøvelse og legg den til i et program for å kontrollere synk.

Historikk og eksisterende programmer skal ikke slettes eller tilbakestilles ved denne oppdateringen.
